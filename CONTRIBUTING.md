# Contribuindo

1. Crie uma branch `feature/nome-da-mudanca` a partir de `develop`.
2. Mantenha o conteúdo em `src/data` e a configuração em `src/config`.
3. Rode `npm run lint`, `npm run typecheck` e `npm run build` antes de abrir o Pull Request.
4. Descreva impacto visual, rotas afetadas e qualquer mudança de ambiente.
5. Faça merge em `develop`; mudanças de produção seguem para `main` após revisão.
